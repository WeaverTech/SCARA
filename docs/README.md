# Dokumentacja

Ten katalog jest przeznaczony na dokumentacje techniczna robota SCARA V1.0.

Proponowana zawartosc:

- schemat polaczen Arduino Mega 2560 ze sterownikami TB6600,
- schemat zasilania 24 V dla silnikow i 9 V dla logiki,
- notatki z kalibracji osi Z i efektora,
- opis procedury homingu z czujnikami optycznymi,
- zdjecia montazu i rewizje mechaniczne.
