# CAD i modele 3D

Ten katalog jest przeznaczony na pliki mechaniczne robota SCARA V1.

Sugerowana organizacja:

- `printed/` - elementy drukowane w 3D z PET-G,
- `profiles/` - elementy związane z profilami aluminiowymi,
- `gearbox/` - przekładnia cykloidalna głównej osi obrotowej,
- `control-box/` - obudowa elektroniki z wentylacją i szyną DIN,
- `exports/` - gotowe eksporty STL/STEP do druku lub podglądu.

Warto dodawać krótkie opisy zmian przy kolejnych wersjach modeli, zwłaszcza
dla elementów wymagających tolerancji montażowych.
