# CAD

Ten katalog jest przeznaczony na modele 3D i pliki produkcyjne robota SCARA.

Sugerowany podzial:

- `printed-parts/` - elementy drukowane w 3D z PET-G,
- `control-box/` - obudowa elektroniki i mocowania sterownikow,
- `gearbox/` - przekladnia cykloidalna glownej osi,
- `exports/` - pliki STL/STEP gotowe do druku lub obrobki.

Duzych plikow binarnych nie nalezy dodawac bez potrzeby. W przypadku wielu
ciezkich modeli warto rozwazyc Git LFS.
