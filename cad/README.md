# CAD

Ten katalog jest przeznaczony na modele 3D i pliki mechaniczne projektu, na przyklad:

- elementy drukowane w 3D (`.stl`, `.3mf`, `.step`),
- modele zlozeniowe,
- uchwyty pod silniki i lozyska,
- obudowe control boxa,
- elementy przekladni cykloidalnej.

Przykladowy dalszy podzial:

```text
cad/
├── arm/
├── cycloidal-gearbox/
├── end-effector/
└── enclosure/
```
